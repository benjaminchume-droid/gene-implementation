# Code of Conduct

## Scope

This repository is a proprietary Gene AI development project.

Contributors, collaborators, and authorized users are expected to
conduct technical discussions professionally and respectfully.

## Expected Behavior

Participants should:

- communicate professionally
- focus criticism on technical decisions rather than individuals
- report security issues responsibly
- respect intellectual-property restrictions
- avoid publishing proprietary source outside authorized channels
- avoid exposing credentials, private data, or user information

## Unacceptable Behavior

The following are prohibited:

- harassment
- threats
- deliberate disruption
- unauthorized disclosure of proprietary code
- credential theft or exposure
- malicious modification of project infrastructure
- publishing private user data
- unauthorized redistribution of Gene AI

## Enforcement

Project maintainers may remove unauthorized contributions, revoke
repository access, or take other appropriate action when project
policies are violated.

Nothing in this document grants rights to use or redistribute
proprietary Gene AI source code.
