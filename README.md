# Gene

Gene is the modular AI architecture for the Velocity AI system.

## Core principle

The neural model is one component.

Gene separates:

- neural reasoning
- genome modules
- context
- persistent memory
- knowledge
- soul
- skills
- evolution
- agents
- capabilities
- tools
- applications
- browser interaction
- orchestration

MCP is a tool-provider protocol, not the entire capability layer.

## Current target

Gene 1:

- 500M parameter model target
- 500K+ effective context architecture
- persistent memory
- modular genomes
- specialist capabilities
- skill-tree evolution
- tool/API/MCP integration
- browser interaction
- filesystem interaction
- application interaction

Training is intentionally separated from the architecture layer.
